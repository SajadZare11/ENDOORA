# Endoora AI Evaluation Datasets — Day 01 Baseline

Golden evaluation sets are required before assigning models/prompts to important runtime tasks.

Planned datasets:
- placement interaction
- exercise generation
- mistake classification
- Writing Mentor
- roleplay
- support triage
- IELTS writing estimate
- IELTS speaking estimate

Each dataset must document source/licensing, privacy status, expected schema, reviewer, scoring method, and version.
