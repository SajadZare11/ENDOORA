# Endoora Environment Variables — Day 01 Baseline

No `.env` file should be created on Day 01.

Planned product-specific prefix: `ENDOORA_`.

Initial examples for Day 02+:
- `ENDOORA_TIMEZONE=Asia/Tehran`
- `ENDOORA_PUBLIC_URL`
- `ENDOORA_API_URL`

Provider secrets are added only when their feature is implemented. Real credentials must never be committed to Git.

- Django secret/settings
- PostgreSQL
