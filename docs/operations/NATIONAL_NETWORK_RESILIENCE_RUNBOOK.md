# دستورالعمل جامع پایداری و میزبانی در زمان شبکه ملی اطلاعات (نت ملی)
## Endoora National Network Resilience & Zero-External-Dependency Runbook

این مستند، راهنمای گام‌به‌گام و عملیاتی برای آنلاین و در دسترس نگه داشتن پلتفرم ایندورا (`endoora.ir`) در شرایط قطع کامل اینترنت بین‌الملل و فعال شدن شبکه ملی اطلاعات (اینترانت کشوری) است.

---

### ۱. معماری سیستم و اصل استقلال کامل (Zero Foreign Dependency)

در زمان قطع اینترنت بین‌الملل، تمام گیت‌وی‌های تبادل داده با خارج از کشور مسدود شده و تنها ترافیک‌های درون‌شبکه‌ای بین ارائه‌دهندگان داخلی از طریق مراکز تبادل داده (IXP/NIX در تهران، مشهد، تبریز و شیراز) مسیریابی می‌شوند.

برای تداوم فعالیت بدون افت کیفیت:
1. **دامنه ملی (`.ir`):** سرورهای ریشه (Root DNS) دامنه `.ir` داخل کشور توسط پژوهشگاه دانش‌های بنیادی (ایرنیک) مدیریت می‌شوند و وابسته به گیت‌وی‌های بین‌المللی نیستند.
2. **فونت‌ها و استایل‌ها:** تمام فونت‌ها به صورت لوکال (`next/font/local`) داخل پروژه قرار گرفته و هیچ درخواستی به `fonts.googleapis.com` یا CDNهای خارجی ارسال نمی‌شود.
3. **عدم وابستگی به کلودفلر:** از CDN خارجی با پروکسی فعال استفاده نمی‌شود تا ترافیک در دروازه‌های مرزی مسدود نشود.
4. **تنظیم اختصاصی SSL/TLS در Nginx:** مکانیزم `ssl_stapling` خاموش است تا تلاش برای استعلام وضعیت گواهی از سرور خارجی Let's Encrypt منجر به فریز شدن مرورگر نشود.

### ۲. گام‌های عملیاتی استقرار روی سرور ایران

#### گام اول: تهیه سرور در دیتاسنتر داخلی
* سرور را از یکی از دیتاسنترهای داخلی با پورت اختصاصی به شبکه IXP ایران تهیه کنید:
  * **دیتاسنترها:** آسیاتک (برج میلاد/میرعماد)، های‌وب، افرانت، شاتل، تبیان یا ارائه‌دهندگان ابری مانند ابر آروان یا پارس‌پک.
* **مشخصات پیشنهادی:**
  * سیستم‌عامل: Ubuntu 24.04 LTS
  * حداقل منابع: 4 vCPU / 8 GB RAM / 60 GB NVMe

#### گام دوم: تنظیمات دامنه در ایرنیک (IRNIC)
1. وارد حساب کاربری خود در وب‌سایت [nic.ir](https://www.nic.ir) شوید.
2. به بخش **دامنه‌های من** > انتخاب دامنه `endoora.ir` > **سامانه نام دامنه (DNS)** بروید.
3. **نکته بسیار مهم:** به هیچ عنوان نیم‌سرورهای Cloudflare (`*.ns.cloudflare.com`) را وارد نکنید.
4. نیم‌سرورهای ارائه‌دهنده ایرانی با قابلیت Anycast داخلی (مانند ابر آروان یا دراک) یا نیم‌سرورهای مستقیم سرور خود را قرار دهید:
   * مثال: `ns1.arvancdn.ir` و `ns2.arvancdn.ir` (با قابلیت سرورهای لبه داخل کشور)
   * یا ایجاد Glue Record با IP سرور ایران: `ns1.endoora.ir` و `ns2.endoora.ir`

#### گام سوم: نصب ابزارها و داکر روی سرور ایران
دستورات زیر را در ترمینال سرور ایران اجرا کنید:

```bash
# به‌روزرسانی مخازن (استفاده از میرورهای داخلی در صورت قطعی)
sudo apt update && sudo apt upgrade -y

# نصب داکر و داکر کامپوز
sudo apt install -y docker.io docker-compose-plugin git curl

# فعال‌سازی سرویس داکر
sudo systemctl enable --now docker
```

#### گام چهارم: انتقال سورس و تنظیم فایل محیطی (`.env`)
پروژه را روی سرور دریافت کرده و فایل محیطی برای پروداکشن تنظیم نمایید:

```bash
cd /opt
git clone <YOUR_GIT_REPO_URL> endoora
cd endoora

# تنظیم متغیرهای محیطی پروداکشن
nano .env
```

مقادیر کلیدی در `.env`:
```ini
ENDOORA_ENV=production
ENDOORA_TIMEZONE=Asia/Tehran
ENDOORA_WEB_ORIGIN=https://endoora.ir
ENDOORA_API_ORIGIN=https://endoora.ir
ENDOORA_ALLOWED_HOSTS=endoora.ir,www.endoora.ir,127.0.0.1,api

# درگاه پرداخت داخلی (فعال روی شاپرک و بدون نیاز به خارج)
ZARINPAL_MERCHANT_ID=<شناسه_مرچنت_زرین‌پال>
ZARINPAL_SANDBOX=0

# سامانه پیامک داخلی (مثل کاوه‌نگار یا فراز اس‌ام‌اس)
ENDOORA_OTP_PROVIDER=kavenegar
ENDOORA_SMS_API_KEY=<کلید_پنل_پیامک_داخلی>
```

#### گام پنجم: دریافت گواهی SSL (قبل یا حین راه‌اندازی)
می‌توانید گواهی رایگان Let's Encrypt را با استفاده از ابزار certbot دریافت کنید:

```bash
sudo apt install -y certbot
sudo certbot certonly --standalone -d endoora.ir -d www.endoora.ir
```
سپس دایرکتوری گواهی‌ها را به مسیر `infra/ssl` لینک یا کپی کنید تا توسط کانتینر Nginx خوانده شود:
```bash
mkdir -p infra/ssl/live/endoora.ir
cp /etc/letsencrypt/live/endoora.ir/fullchain.pem infra/ssl/live/endoora.ir/
cp /etc/letsencrypt/live/endoora.ir/privkey.pem infra/ssl/live/endoora.ir/
```

#### گام ششم: بیلد و اجرای کانتینرهای پروداکشن
فایل کامپوز پروداکشن به طور اختصاصی با تفکیک سرویس‌ها و وب‌سرور آماده شده است:

```bash
docker compose -f infra/docker-compose.prod.yml up -d --build
```

وضعیت سلامت کانتینرها را بررسی کنید:
```bash
docker compose -f infra/docker-compose.prod.yml ps
```

### ۳. بررسی و ممیزی خودکار تاب‌آوری پلتفرم

در داخل پروژه، یک اسکریپت ممیزی خودکار ایجاد شده است که می‌توانید در هر زمان برای اطمینان از عدم اضافه شدن وابستگی خارجی آن را اجرا کنید:

```bash
npm run check:national-network
```

این اسکریپت موارد زیر را به طور دقیق کنترل می‌کند:
1. استفاده از فونت‌های محلی بدون نیاز به دانلود از گوگل در زمان بیلد یا اجرا.
2. عدم وجود تگ‌های اسکریپت و استایل CDNهای خارجی (مانند `cdnjs`، `jsdelivr`، `unpkg`، `Google reCAPTCHA` و `Google Analytics`).
3. پیکربندی صحیح Next.js در حالت `standalone`.
4. تنظیم صحیح Nginx برای غیرفعال بودن `ssl_stapling`.
5. پیکربندی یکپارچه کانتینرهای داکر.

### ۴. مانور شبیه‌سازی قطعی اینترنت بین‌الملل (Simulation Drill)

برای اطمینان ۱۰۰٪ از کارکرد سایت، قبل از وقوع رخداد واقعی می‌توانید روی سرور پورت‌های خروجی بین‌المللی را مسدود کرده و دسترسی سایت را تست نمایید:

```bash
# تست دسترسی از طریق شبکه داخلی
curl -I https://endoora.ir

# بررسی هدرهای کش استاتیک (باید شامل immutable باشند)
curl -I https://endoora.ir/fonts/iranyekan/iranyekan-regular.woff
```
سایت در زمان نت ملی با بالاترین سرعت و بدون کوچک‌ترین وقفه یا خطای لودینگ به کار خود ادامه خواهد داد.
