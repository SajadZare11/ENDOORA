# Endoora Incident Response — Day 01 Baseline

## Priority
Protect users, data, money, and secrets before restoring convenience.

## Initial sequence
1. Identify affected layer and scope.
2. Stop or disable the unsafe feature/provider path when necessary.
3. Preserve logs/evidence without exposing secrets.
4. Rotate compromised credentials if confirmed.
5. Restore from known-safe state when required.
6. Verify authorization/payment/data integrity.
7. Communicate user-facing impact appropriately.
8. Add regression test/monitoring.
9. Record root cause and corrective action.

Specific runbooks will be expanded for auth, payments, AI, storage, DNS/SSL, worker queues, privacy, and moderation.
