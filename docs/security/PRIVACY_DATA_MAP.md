# Endoora Privacy Data Map — Day 01 Baseline

## Principles
- Collect only data required for a defined product purpose.
- Separate public profile data from private identity/verification data.
- Raw writing/audio/chat is not automatically permanent learner evidence.
- Obtain explicit consent for microphone/audio and sensitive analysis.
- Define retention before collecting new sensitive content.
- Support export/correction/deletion subject to legitimate financial/legal retention.
- Do not send raw learner content to product analytics.

## High-sensitivity planned data
- Authentication/session data
- Learner writing
- Voice recordings/transcripts
- Teacher verification records
- Messages/support cases
- Payment records
- Linked learner/teacher educational evidence

Field-level purpose, lawful basis/consent, retention, access roles, export, and deletion behavior will be added with each schema.
