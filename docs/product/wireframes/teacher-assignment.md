# Wireframe 4 — Teacher Assignment

`Teacher Home`
→ **Teach**
→ **Assignments**
→ **Create Assignment**
→ `Choose class/learners`
→ `Select objectives/questions`
→ `Delivery settings`
→ `Review`
→ **Publish**
→ `Assignment detail`

## Form behavior

Each stage has Back, Save and Continue Later and Cancel.
Publishing is a distinct final action; saving a draft never publishes.

## Recovery

- no class: explain how to create/select a class;
- unavailable question: preserve draft and identify the affected item;
- concurrent edit later: warn before overwriting;
- expired session: re-authenticate and resume draft;
- wrong teacher/class: deny server-side.

## Findability target

Teacher: **Teach → Assignments → Create Assignment** = three navigation decisions.
