# Wireframe 2 — Daily Mission

**Goal:** a returning learner answers “What should I do now?” in five seconds.

`Learner Home`
→ dominant **Continue today's mission**
→ `Mission overview`
→ `Task`
→ `Feedback`
→ `Next task`
→ `Mission complete`
→ `Next best action`

## Home hierarchy

1. Today card above the fold.
2. Short reason: “Why this action?”
3. Compact supporting context only: due review, urgent assignment, next class.
4. No Billing/Library/Settings tile grid.

## Recovery

- No mission yet: generate/load bounded mission or show Placement first-time state.
- Offline: expose only genuinely available saved work.
- Failed task load: Retry without losing completed mission items.
- Refresh: reopen current task/last confirmed state.

## Findability target

From learner primary navigation, **Home** immediately exposes Today.
