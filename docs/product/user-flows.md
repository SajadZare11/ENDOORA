# Endoora Day 05 Critical User Flows

## Frozen journey set

| Flow | Entry | Primary completion | Later roadmap owner |
|---|---|---|---|
| Placement → Path | Public Home / learner first-time Home | learner reaches personal path / Today | Days 14–20 |
| Daily Mission | Learner Home | useful mission completion + next action | Day 20 |
| Learn Now | Teachers & Classes | matched offer progresses to booking | Days 37–39 |
| Teacher Assignment | Teacher Teach | reviewed assignment published | Days 33–36 |
| Fixed Class Enrollment | Public/Learner Classes | confirmed enrollment or explicit waitlist | Day 40 |
| IELTS Attempt | IELTS Hub | attempt safely submitted and report available | Days 44–48 |

## Cross-flow conventions

- one dominant CTA per screen;
- Back / Save and Continue Later / Cancel for long flows;
- refresh/reconnect recovery;
- deep links survive login;
- permission failures are explicit;
- loading, empty, error, offline/interrupted and expired-session states are specified;
- raw sensitive evidence is never stored merely to make navigation recovery easier.
