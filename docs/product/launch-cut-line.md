- Bilingual public shell
- Secure authentication, roles, consent, sessions, data controls
- Placement core and transparent CEFR estimate
- Learning path and Daily Mission
- Validated AI exercise generation
- SRS vocabulary and progress analytics
- Teacher dashboard, verification, classes, question bank, assignments, grading
- Configurable Premium plan: 90 days, 420,000 تومان
- Orders, entitlements, billing, ZarinPal verified server-side payment flow
- Admin, audit logs, feature flags, support, notifications, analytics
- PWA/resilience, accessibility, security/privacy, backups, staging, DNS/HTTPS, launch checks

## V1 in one sentence
Endoora helps an English learner assess their current level, receive a personalized path and daily practice, preserve useful learning evidence, work with teachers, pay securely for approved services, and track progress in one bilingual learning system.

## Change rule
Any maturity change requires a written reason, risk review, dependency review, and test-impact review.
