# Endoora Brand Conflict Precheck

## Date
17 August 2026

## Purpose
Record an obvious-conflict precheck only. This is **not** a trademark clearance or legal opinion.

## Basic web-search observations
A basic web search found existing public uses of the word/name “Endoora”, including:
- a YouTube presence using “THE ENDOORA” in a personal-growth context;
- a Turkish real-estate project referred to as “Endoora Bahçeşehir”.

A targeted web query did not provide a reliable basis to conclude whether an identical educational/software trademark is registered in relevant classes or jurisdictions.

## Decision
Continue using Endoora as the project working/public name because the founder has approved it and owns `endoora.ir`, while retaining **formal trademark/legal clearance as a launch dependency**.

## Required later review
Before major paid marketing or international expansion:
- search relevant Iranian trademark records;
- search WIPO Global Brand Database;
- search relevant international/national registries for software, education, marketplace, and related classes;
- obtain professional legal advice when commercial exposure justifies it.

Do not represent this precheck as proof that the name is legally clear.
