# Day 18 - Transparent Placement Scoring Model

## Purpose

The placement report provides a learning estimate. It is not an official CEFR certification.

## Score calculation

Each assessed section produces a percentage score.

Current sections:

- Grammar
- Vocabulary
- Reading
- Listening
- Speaking
- Writing

Overall score:

```
sum(section scores) / number of sections
```

## CEFR estimate

The system maps the overall score into a provisional band:

| Score | Estimate |
|---|---|
| 90-100 | C1 |
| 75-89 | B2 |
| 60-74 | B1 |
| 45-59 | A2 |
| 0-44 | A1 |

## Confidence

Confidence depends on available evidence.

The report must show:

- number of evaluated items
- assessed skills
- evidence behind the estimate
- limitations

## Product rule

Never describe the result as:

"Your official CEFR level is..."

Use:

"Your estimated learning level is..."
