# Day 24 Writing Mentor v1

The Writing Mentor provides formative writing feedback, three-tier reference rewrites (A2/B2/C2), revision coaching, and transparent estimated IELTS rubric breakdowns.

For complete architectural and rubric specifications, see [docs/ai/writing-rubric.md](../ai/writing-rubric.md).

## Core Principles
1. **Learner Voice Preservation**: Reference rewrites are explicitly labeled as educational examples and never replace student voice.
2. **Score Range Transparency**: Formative IELTS scores and CEFR estimates are presented as ranges (e.g., Band 6.0 – 6.5) with transparent disclosures under Product Constitution Rule #8.
3. **Dialect vs Grammar**: Style suggestions are separated from structural errors.
4. **Selective Mistake Genome Sync**: Only accepted corrections feed the Mistake Genome; dismissed suggestions are omitted.
