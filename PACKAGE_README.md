# Endoora Day 01 — Part 1 Package

Copy the contents of this package into your local `Endoora` project root.

After copying, your project should contain:

Endoora/
└── docs/
    ├── decisions/
    ├── operations/
    │   └── domain-map.md
    └── product/
        ├── endoora-naming.md
        └── product-constitution.md

The `docs/decisions/` directory is intentionally empty at this checkpoint.
